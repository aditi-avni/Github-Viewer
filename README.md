# GitHub Profile Viewer

A responsive GitHub Profile Viewer built with HTML, CSS, and JavaScript that fetches real-time user data from the GitHub API.

## 🚀 Features

- Search any GitHub username
- Display profile information
  - Profile picture
  - Name
  - Username
  - Bio
  - Followers
  - Following
  - Public repositories
  - Location
  - Company
- Direct link to GitHub profile
- Clickable repository list
- Error handling for invalid usernames
- Responsive dark-themed UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GitHub REST API

## 📂 Installation

1. Clone the repository

```bash
git clone https://github.com/aditi-avni/Github-Viewer.git
```

2. Open the project folder

```bash
cd Github-Viewer
```

3. Open `index.html` in your browser

## 📖 How It Works

1. Enter a GitHub username.
2. Click the Search button.
3. The application fetches user data from the GitHub API.
4. Profile information is displayed dynamically.
5. Public repositories are listed as clickable links.

## 🔗 GitHub API Endpoint

```text
https://api.github.com/users/{username}
```

Repositories Endpoint:

```text
https://api.github.com/users/{username}/repos
```
